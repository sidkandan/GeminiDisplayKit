# PROMPT ARENA — Demo Runbook

**One-liner:** Anyone invents a monster and coaches it in plain English; every monster is trained by its **own Gemini managed agent** (remote sandbox + code-execution self-test); then they battle live. Built today at the Google I/O hackathon.

## Run it
```bash
# SAFE PATH (no network needed) — defaults + bracket + arena UI
.venv/bin/python run_demo.py --defaults-only

# FULL PATH — train every monster via managed agents, then bracket + UI
.venv/bin/python run_demo.py --hatch

# UI only, on the existing (golden) bracket
.venv/bin/python run_demo.py --serve-only      # http://localhost:5001
```
**Pre-warm before the slot:** run `--hatch` once so strategies, traces, sprites, and audio are cached and `data/tournament.json` is frozen as the golden snapshot. On stage you then run from cache — instant, offline-safe.

## 3-minute stage script (with the tool tour baked in)
- **0:00 — Hook.** "Hackathons are full of chatbots. We built a *stadium.* Anyone invents a monster and coaches it in plain English — and every monster is trained by its own Gemini managed agent. Watch."

- **0:40 — The Hatchery → `Managed Agents + Code Execution + Structured Output`.** Open the trace panel. "We don't just prompt a model. Each monster gets its **own managed agent in a remote Linux sandbox**. It reads the type chart, writes a Python strategy from the coaching, and **runs a self-test simulation — real code execution — to tune itself**, then emits a structured strategy. 7 of 10 wins in self-test." Point at `reasoning` + `self_test` + the steps. "That's the managed-agents prize on one screen."
- **1:10 — Sprites → `Image Generation (Nano Banana)`.** "Every monster's look is generated by Gemini image-gen — original art, on the fly."
- **1:25 — The bracket → `Text-to-Speech`.** Start the tournament. Round 1 = 2×2 grid: HP bars, **SUPER EFFECTIVE** flashes, taunt bubbles, an **AI sportscaster** calling the action. The hook: "**Cindermaw and Emberton are both Pyro, same moves** — but one was coached 'pure glass cannon' and the other 'patient defense.' Watch them play *completely* differently. That's the coaching, compiled by the agent, on the field."
- **2:20 — The Final.** Center stage, slower, commentary peaks, killing blow → **CHAMPION** (glasses buzz / name on screen if used).
- **2:40 — The turn (Impact).** "Plain-English coaching from strangers, compiled by managed agents into self-tested code that competes live. It's a template for fleets of individually-steered autonomous agents — and it touches the whole Gemini stack: managed agents, code execution, structured output, function calling, image-gen, and TTS."
- **2:55 — Provenance.** "100% built today — public repo, github.com/sidkandan/prompt-arena."

## Q&A defense
- **"What did you build today?"** → Everything. Fresh repo, first commit timestamped at event start; here's the commit log. Engine + arena + managed-agent hatchery, all new.
- **"Is this health/medical?"** → No. It's a game. No health data, no advice. (We deliberately steered clear of the banned categories.)
- **"How is this *managed agents*, not just API calls?"** → Each monster is a managed agent with its **own remote sandbox** that **writes and runs code** to self-test — server-side code execution + persisted state, not one completion. Show the env id + trace.
- **"Real-world use?"** → A pattern for fleets of individually-coached autonomous agents (support, research, sims). The arena is just the legible, fun demo of it.

## Reliability ladder (protect the 45% live-demo score)
1. **Primary:** pre-warm with `--hatch`; run `--serve-only` on stage (cached strategies/traces/sprites/audio + frozen `data/tournament.json`).
2. **API slow/down on stage:** trace panel shows pre-captured steps; battles replay from the golden snapshot.
3. **WiFi dies:** everything is local files; the UI animates the stored bracket; sprites/audio are local. Offline-safe by design.
4. **Hard net:** the recorded 1-minute video.
